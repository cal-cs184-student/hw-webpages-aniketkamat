Overview

Give a high-level overview of what you implemented in this homework. Think about what you've built as a whole. Share your thoughts on what interesting things you've learned from completing the homework. In this assignment, I implemented ray tracing methods using techniques/algorithms such as BVH construction, light sampling, Russian Roulette termination, and adaptive sampling. I started by learning how to generate rays and see where they intersect with a scene before constructing a data structure (Bounding Volume Hierarchy) to efficiently check for intersections. I then implemented direct and indirect illumination. With the former, I learned how different sampling methods can produce different amounts of noise. With the latter, I got experience dealing with a complex recursive problem and saw how each additional bounce helps produce a realistic image. The most interesting part of this project was the Russian Roulette method since I saw how different continuation probabilities affected the rendering time. Lastly, I implemented adaptive sampling to produce high quality images at a lower computational cost. I learned how basic statistics such as a pixel mean/variance can be used to see if a pixel needs more samples.
